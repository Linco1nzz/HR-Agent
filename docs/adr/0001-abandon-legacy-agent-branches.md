# 0001. 不复用已回滚的旧 Agent 分支，按 SPEC 从零实现

Status: Accepted (2026-11-24)

仓库里存在两版已被整体回滚的 Agent 实现：`feat/hr-agent`（约 9.8k 行，三张 agent 表）与
`backup/agent-wip-20261124`（约 17k 行，四张任务表 + 模板执行器 + 7 条 ADR）。两者都改动了
30 个以上现有文件，与本轮 `doc/SPEC_REFACTOR.md`「禁止大面积重构、优先增量追加」的约束直接
冲突，回滚本身也说明其范围不可接受。决定：以 SPEC 为唯一需求与设计依据从零实现，旧分支视为
废弃方案，不合并任何代码；旧分支的 ADR 结论只作为背景信息，需要重新论证后才采用。
