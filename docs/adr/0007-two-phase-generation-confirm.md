# 0007. 生成类两段式确认与可编辑参数表单

Status: Accepted (2026-11-24) · Amends 0004

本期只有 JD 生成在调用 Dify 前弹出「参数确认表单」：字段来自 `generate_jd` 的参数 schema，
可编辑，用户确认后才执行；评分标准与面试方案生成保持直接执行，但工具注册表保留「生成前确认」
扩展位。生成结果一律不落库，保存动作另设 `save_resource` 确认卡片（可编辑落库字段）。
`score_resume` 的表单选择目标 JD 与简历（可改选，并支持表单内直接上传新简历），确认后执行评分
并落库，不再二次确认。理由：把自然语言里的岗位信息先落成结构化参数并经人确认，避免 AI 猜错；
同时不给低风险生成加多余的闸门。
